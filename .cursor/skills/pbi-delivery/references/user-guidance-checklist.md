# Per-stage “Your tasks” guidance (required)

Every stage response must tell the human what **they** need to do next. Agents produce artifacts; humans confirm business truth, provide files, lock stages, and make release decisions.

## Stage 1 — Requirements

- Correct classification (scenario + NEW/ONGOING)  
- Answer Ambiguous/Missing questions  
- Add/remove/change requirements  
- Lock stage 1  

## Stage 2 — Architecture

- Confirm systems/gateway/security assumptions  
- Approve Mermaid flow  
- Review page layouts / visuals  
- Lock stage 2  

## Stage 3 — Feasibility

- Provide PBIP, schema sample, or MCP access  
- Resolve Ambiguous column mappings  
- Confirm relationships  
- Send Missing items to Data Engineering  
- Lock stage 3  

## Stage 4 — Build

- Confirm report path / convert PBIX→PBIP if needed  
- Reopen Desktop after TMDL edits  
- Finish Desktop-only visual steps from the checklist  
- Lock stage 4  

## Stage 5 — QA

- Confirm test-case column format  
- Execute or report results for each case  
- Set severities / accept fails  
- Human go/no-go  
- Lock stage 5  

## Stage 6 — Documentation

- Confirm template  
- Review compiled doc for gaps  
- Add org-specific header/footer if needed  
- Lock / finalize stage 6
